# housing_dashboard
Housing inequality in remote indigenous communities in Australia

This project explores housing inequality issues in Indigenous-majority remote areas in Australia. Using data from the Australian Bureau of Statistics (ABS), it examines how rising rental costs and low household income affect affordability and access to housing. Although the interactive Tableau dashboard is unavailable due to license expiry, key visualisations are included as images and supported by a full analysis report.

## Project Overview
Remote Indigenous communities in Australia face unique housing challenges, including:
- Rising rental fees
- Low median household incomes
- Higher unemployment rates
- Overcrowding and affordability issues

This project analyses public datasets from ABS to identify trends in rental costs, income disparities, and employment by remoteness. It also provides policy recommendations to address housing equity.

## Key Insights
- Rental fees in remote areas have increased faster than household income.
- Income and employment levels are significantly lower in very remote areas.
- These disparities lead to increased cost burden, overcrowding, and inequality.

## Recommendations
1. **Expand culturally appropriate public housing** to reduce cost burdens for low-income Indigenous populations.
2. **Invest in local infrastructure** to improve employment rates and access to services in remote areas.
